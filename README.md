# 잿빛 구역 (Ash Zone)

무너진 도시에서 변이체의 밤을 버티는 2.5D 서바이벌 FPS입니다.
낮에는 상자를 뒤져 고철을 모으고 바리케이드·함정을 세우고 작업대에서 무기를 갖추고, 밤에는 몰려오는 변이체를 막아냅니다. 5번째 밤마다 보스 '도살자'가 나타납니다.

- 브라우저에서 바로 실행: `index.html` 하나 (외부 라이브러리·이미지·오디오 파일 없음, 그래픽과 소리는 모두 코드로 생성)
- PC와 태블릿 모두 지원, 앱으로 설치 가능(PWA, 오프라인 실행)

## 조작
- **PC**: WASD 이동 · 마우스 조준 · 클릭 사격 · R 재장전 · 1~5/Q 무기 교체 · Shift 달리기 · F 바리케이드 · G 가시 함정 · E 작업대(낮) · N 바로 밤 시작 · M 지도 · Esc 일시정지
- **태블릿**: 왼쪽 드래그 이동(끝까지 밀면 달리기) · 오른쪽 드래그 조준 · 화면 버튼으로 사격·재장전·교체·설치

## 파일
- `index.html` 게임 전체
- `manifest.webmanifest`, `sw.js`, `icons/` 앱 설치·오프라인용
